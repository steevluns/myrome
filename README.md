# Unscreen

تطبيق أندرويد (Kotlin) يوقظ الشاشة عند قلب الجهاز (الشاشة للأسفل) بصلاحية الروت.

- الحزمة: `com.unscreen`
- أقل إصدار: Android 7.0 (API 24)
- المعماريات: arm64-v8a / armeabi-v7a

## البناء على GitHub
1. ارفع كل محتويات هذا المجلد إلى مستودع جديد (فرع `main`).
2. افتح تبويب **Actions** ← **Build APK** (يبدأ تلقائياً، أو اضغط Run workflow).
3. بعد اكتمال البناء ادخل على العملية وانزل إلى **Artifacts** ← حمّل `Unscreen-APK`.
4. فك الضغط وثبّت `app-release.apk`، ثم امنح التطبيق صلاحية الروت.
