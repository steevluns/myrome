# Crave setup for myrome

This repository targets Samsung Galaxy J7 Prime (SM-G610F, codename `on7xelte`) with LineageOS 19.1 / Android 12L.

## 1. Get Crave credentials

Crave credentials are account-specific and cannot be generated by this repository. Sign in to your Crave/FOSS dashboard and open **API Keys** to create/download your `crave.conf`. If you do not have an account, request access through the Crave service first.

## 2. Add GitHub Actions secrets (do not commit credentials)

Open **Settings → Secrets and variables → Actions → New repository secret** in this repository and add:

- `CRAVE_USERNAME`: the username/email shown in your Crave configuration.
- `CRAVE_TOKEN`: the value of the `Authorization` field from `crave.conf`, without quotes or any `:`, spaces, or commas.
- `CRAVE_FLAGS` (optional): extra Crave CLI flags only if needed.

Never paste these values into a public file, commit, issue, or chat. Do not upload the real `crave.conf` to the repository. The tracked `crave.conf.sample` is only a template.

## 3. GitHub Actions permissions

In **Settings → Actions → General → Workflow permissions**, select **Read and write permissions** only if the workflow needs to commit or publish files. Keep the token permission minimal.

## 4. Build prerequisites

The credentials alone do not guarantee a successful ROM build. The project must also have a supported Crave base project, a correct local manifest, and a build workflow that initializes LineageOS 19.1, applies the `on7xelte` device manifest, integrates MindTheGapps ARM64, and runs the correct lunch/build commands.

The currently tracked `crave.conf.sample` has an empty `projects` list; do not guess a project ID. Confirm the available project ID using the Crave CLI/account project list before setting it. The value `85` mentioned in older notes must be verified against the current account/project list.

## Security note

No real Crave username, token, or API key is stored in this repository. GitHub Actions reads the values from repository secrets at runtime.
